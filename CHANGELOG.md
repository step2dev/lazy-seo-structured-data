# Changelog

All notable changes to `lazy-seo-structured-data` will be documented in this file.

## Unreleased

- Added configurable JSON encoding flags.
- Added `@graph` support for rendering multiple JSON-LD schemas in one script.
- Added strict/fallback behavior for unknown schema types.

- Added stronger feature tests for schema output, JSON flags, unknown types, and graph rendering.
